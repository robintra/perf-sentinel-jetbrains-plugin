// Java PSI classes reached only from the optional com.intellij.java module.
//
// JavaAnchorResolver and JpaTableAnchorResolver are registered exclusively in
// META-INF/perf-sentinel-java.xml, which the platform loads only when
// com.intellij.java is present. IDEs without Java support never load them, so
// these classes can never be reached at runtime there.
//
// The Plugin Verifier still scans the whole jar and cannot resolve the classes
// against an IDE that does not ship the Java module, so it reports them as
// compatibility problems. IDEs that do bundle the Java module resolve them and
// report nothing, which is why only the 253 targets without Java are affected.
//
// Every class is listed on its own line on purpose. A broad com.intellij.psi.*
// pattern would also hide genuine problems on platform PSI classes, and a new
// Java class reached from the core would silently stop being reported.
//
// Format: <plugin_xml_id>:<plugin_version>:<problem_description_regexp>
